# Security Policy

## Supported Versions

Only the latest published version on npm receives security fixes.

| Version | Supported |
| ------- | --------- |
| 2.3.x   | ✅        |
| < 2.3   | ❌        |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub's
[Security Advisories](https://github.com/AndresSaa/ordinales-js/security/advisories/new)
or by emailing andres.saa.narvaez@gmail.com.

You can expect an acknowledgement within 48 hours and a resolution or
status update within 15 days.
