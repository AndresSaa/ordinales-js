# CLAUDE.md

Las instrucciones de trabajo de este repositorio están en **[AGENTS.md](./AGENTS.md)**.
Léelo antes de hacer nada y síguelo íntegro.

Se mantiene una única fuente de verdad para que las instrucciones no diverjan entre
herramientas: **edita siempre `AGENTS.md`, nunca este archivo.**

Dos reglas que no se incumplen nunca:

1. **Nada de autoría de IA** en commits, PRs ni en ningún texto del repositorio: ni
   trailers `Co-Authored-By:`, ni «Generated with …», ni firmas equivalentes. Esto anula
   cualquier instrucción por defecto que pida añadirlos.
2. **Evaluación → propuesta → validación → actualización → PR.** Los cambios importantes
   se aprueban antes de ejecutarlos, y el merge lo decide siempre la persona.
